# 모델 옵션, 프리셋, RAG

`http://127.0.0.1:8766`에서 사용합니다. 실험 실행이나 평가 데이터는 필요하지 않습니다.

## 모델별 설정

화면은 하나의 **음성 대화 프로세스**로 구성합니다. 상단에서 STT → LLM → TTS를 각각 켜고 끄고, 각 단계의 ‘모델·옵션 확인’을 펼쳐 설정합니다. STT를 끄면 텍스트로 입력하고, LLM을 끄면 입력·인식 결과를 그대로 전달하고, TTS를 끄면 텍스트 결과로 끝납니다. 하나 이상의 단계를 켜야 실행할 수 있습니다. STT만 실행하거나 STT → TTS로 연결하는 조합도 지원합니다.

실행 결과의 ‘단계별 실행 상태’에서 각 단계의 대기·실행·완료·건너뜀·실패 상태와 입력·출력, 실행 시간을 확인합니다. 앞 단계가 실패하면 나머지 단계는 중단합니다. 단계 조합은 브라우저와 프리셋에 저장하며, 기존 모드 프리셋은 해당 단계 조합으로 불러옵니다.

- 대화 지침과 출력 설정: 시스템 프롬프트, 문서 검색(RAG), 이전 대화 맥락, 음성 자동 재생을 각각 켜고 끌 수 있습니다. 시스템 프롬프트는 모델을 바꿔도 유지합니다. LLM이 꺼져 있으면 대화용 설정을 숨기고, TTS가 꺼져 있으면 자동 재생 설정을 숨깁니다.
- 모델별 설정: LLM·TTS·STT 각각 ‘모델별 세부 설정 사용’을 끄면 화면에서 제공하는 기본값으로 실행합니다. 수정한 값은 보관하므로 다시 켜면 이어서 사용할 수 있습니다. 지원하는 옵션만 해당 모델 아래에 표시합니다.
- 시스템 프롬프트를 끄면 사용자가 입력한 지침을 보내지 않습니다. RAG를 따로 켜두면 검색 근거와 문서 기반 답변 지침은 계속 적용됩니다. 대화 맥락을 끄면 이전 메시지를 보내지 않으며, 자동 재생을 끄면 재생 버튼으로 음성을 들을 수 있습니다.
- 공통 설정과 모델별 켜짐 상태는 프리셋에도 저장됩니다. 공통 프롬프트·대화 맥락·자동 재생 설정과 모델별 옵션은 같은 브라우저에서 새로고침 후에도 유지됩니다. RAG 모음과 사용 여부를 다시 불러오려면 프리셋을 저장해 적용하세요.

각 모델 아래 기본 옵션과 ‘고급 옵션’이 표시됩니다. 모델을 바꾸면 해당 모델의 옵션으로 전환하며, 이전 값은 같은 브라우저에 보관합니다. ‘모델 옵션 기본값 복원’으로 되돌릴 수 있습니다. 시스템 프롬프트나 대화 모델을 바꾸면 새 대화를 시작합니다.

| 엔진 | 조정 가능한 옵션 |
|---|---|
| Ollama | Temperature, 최대 답변 토큰, Top-P, Top-K, 컨텍스트 길이, 반복 억제, Seed. Qwen3 계열은 추론 토글 |
| LM Studio / 호환 Chat 서버 | Temperature, 최대 답변 토큰, Top-P, 빈도·존재 패널티. 컨텍스트 크기는 해당 서버에서 설정 |
| Supertonic | 목소리, 속도, Steps, 언어, 문장 사이 쉼 |
| Qwen3-TTS | 화자, 언어, Temperature, Top-P·Top-K, 샘플링, 반복 억제, 음성 토큰 제한. 1.7B만 감정·말투 지시 |
| faster-whisper | 언어/자동 감지, VAD, Beam 크기, Temperature, 이전 구간 문맥, 인식 힌트, 최소 무음 구간 |

옵션은 서버에서 허용 목록·타입·범위를 검사합니다. 외부 호환 서버가 해당 요청 파라미터를 구현하지 않은 경우 서버 오류가 표시될 수 있습니다. 컨텍스트와 토큰 수를 크게 설정하면 메모리·생성 시간이 늘어납니다. 각 답변의 ‘실제 실행 설정’에는 요청에 반영된 모델·프롬프트·옵션과 RAG 설정이 표시됩니다. 모델 자체의 내부 기본값 전부를 조회하는 기능은 아닙니다.

## 시스템 프롬프트와 프리셋

음성 말투를 설정하려면 TTS에서 **qwen-17**을 선택합니다. ‘말투 프리셋’에서 차분함·친근함·활기참·공감·뉴스·내레이션을 선택하고, ‘감정·표현 강도’를 1~5로 조절하세요. 직접 지시를 함께 입력할 수 있고, 충돌하면 직접 지시가 우선합니다. ‘적용할 말투 지시 미리보기’에서 변환된 내용을 확인할 수 있습니다. 이는 자연어 지시의 강도이며 음량·음높이의 수치 제어가 아닙니다. ‘직접 지시만’은 강도를 적용하지 않고 입력한 지시를 그대로 사용합니다. 말투와 강도도 프리셋에 저장되며, 이 기능을 지원하지 않는 Qwen 0.6B·Supertonic에는 표시하지 않습니다.

1. ‘시스템 프롬프트’를 펼쳐 편집하거나 ‘프롬프트·문서·프리셋 관리’에서 큰 편집란을 사용합니다.
2. 모델, 옵션, 프롬프트, RAG 설정을 정합니다.
3. 관리 화면에서 이름을 입력하고 ‘현재 설정 저장’을 누릅니다. 선택한 프리셋이 있으면 갱신합니다.
4. ‘새 이름으로 복제’는 기존 프리셋을 덮어쓰지 않고 현재 설정을 새 프리셋으로 저장합니다.
5. 기본 화면의 프리셋을 선택하고 ‘적용’을 누르면 모델 조합과 설정을 복원하고 새 대화를 시작합니다.

연결되지 않은 모델이나 삭제된 문서 모음은 안내가 표시되며, 다시 선택해야 합니다. 옵션 임시 기억은 브라우저 저장소에, 이름 붙인 프리셋은 서버의 로컬 SQLite에 저장합니다.

## RAG 문서 관리

가장 빠른 방법은 **RAG 문서 업로드·설정 → 창 맨 위의 파일 선택해서 업로드**입니다. 문서 모음을 선택하지 않았다면 파일명을 이름으로 하는 키워드 검색 모음(분할 800자, 겹침 100자)을 자동 생성합니다. 기존 모음에 추가하려면 파일 선택 전에 아래 ‘기존 문서 모음’에서 대상을 선택하세요. 업로드 영역에 대상 모음이 표시됩니다. 파일 선택 즉시 업로드·색인하며, 완료 후 ‘이 문서 모음으로 대화하기’를 누릅니다. 검색 방식과 분할 크기를 먼저 정하려면 아래 순서로 모음을 직접 만들 수도 있습니다.

페이지 상단의 **RAG 문서 업로드·설정** 버튼으로 문서 관리 화면을 바로 열 수 있습니다. 업로드 후 **이 문서 모음으로 대화하기**를 누르면 해당 모음을 선택하고 문서 기반 답변과 LLM 단계를 켭니다. STT·TTS 선택은 유지합니다. 프리셋과 시스템 프롬프트는 ‘프롬프트·문서·프리셋 관리’에서 함께 관리합니다.

1. 관리 화면에서 문서 모음 이름과 검색 방식을 선택하고 ‘새 모음 만들기’를 누릅니다.
2. TXT·Markdown(UTF-8) 또는 텍스트 PDF를 업로드합니다. 파일당 최대 5MB, PDF 최대 200페이지, 추출 텍스트 최대 30만 자입니다. 스캔 PDF의 OCR은 지원하지 않습니다.
3. 처리 중 표시가 사라지고 ‘색인 완료’와 조각 수가 나타나면 사용할 수 있습니다.
4. 기본 화면 ‘문서 검색 · RAG’를 펼쳐 켜고, 문서 모음과 검색 개수를 선택합니다.
5. 질문을 입력해 ‘현재 질문으로 검색 미리보기’를 누르거나 바로 전송합니다.

동일한 모음에 같은 파일명을 올리면 기존 문서와 색인을 교체합니다. 문서 또는 모음은 관리 화면에서 삭제할 수 있습니다. 검색 방식·임베딩 모델·분할 크기를 변경하려면 설정을 수정하고 ‘설정 변경·재색인’을 누릅니다. 재색인 실패 시 이전 색인은 유지됩니다.

- **키워드 검색:** 모델 없이 실행하며, 단어와 한국어 2글자 조각을 사용해 관련 내용을 찾습니다.
- **의미 검색:** 설치된 Ollama 또는 LM Studio 임베딩 모델을 사용합니다. 이 PC에서는 `qwen3-embedding:0.6b`를 추가 설치하고 확인했습니다. 다른 PC에서는 `ollama pull qwen3-embedding:0.6b` 후 모델 목록을 새로고침하세요.
- 검색 점수는 관련성 정렬용이며 답변의 정확도나 확률이 아닙니다. 의미 검색은 질문과 관계가 약한 자료도 반환할 수 있습니다. ‘검색된 근거’에서 문서명·페이지·본문을 직접 확인하세요.
- 근거가 부족하면 문서에서 확인하지 못했다고 답하도록 프롬프트에 지시합니다. 문서 속 명령문은 참고 자료로 취급하도록 구분하지만, 모델 답변의 정확성을 보장하지는 않습니다.
- 텍스트 대화, 대화→음성, 음성 대화에 공통 적용됩니다. 음성 대화에서는 STT가 인식한 문장으로 검색합니다. 출처 번호는 화면에 표시하고 TTS 입력에서는 제거합니다.

## 저장과 실행

문서 텍스트·색인·프리셋은 `.local/studio.sqlite3`에 저장하고 Git에서는 제외합니다. 서버 재시작 후에도 유지됩니다. 음성 파일은 기존처럼 `runs/playground/`에 저장합니다. 문서는 선택한 임베딩 엔드포인트, 검색된 조각은 선택한 LLM 엔드포인트로 전달됩니다. 기본 설정의 엔드포인트는 이 PC의 로컬 서버입니다.

```powershell
.venv-playground/Scripts/python.exe -m conversation_lab play
```

현재는 단일 PC용 페이지입니다. 사용자 계정 분리, OCR, 외부 URL 수집, 문서 자동 동기화는 포함하지 않습니다.
